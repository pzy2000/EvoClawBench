# Predicted results for clean (non-failed) reruns

> **Internal planning document. These are predictions, not measurements. Do not copy any number from this file into the paper, rebuttal, or artifact.** Once real reruns exist, replace the predictions with the measured values.

All numbers use the official 100-task basis (`task_00_sanity` excluded), are execution-only mean scores in percent, and are ordered Baseline / PreSkill / PostSkill. Observed values come from `review/split_analysis.md` (generated by `review/split_analysis.py` from the ten main-table JSON files).

## Why the current rows are not "normal" results

- **OpenClaw, all five rows.** All 79 generated tasks (`task_22`–`task_100`) end with `status=timeout` and score 0 in almost every mode (per-task wall time 138–323 s against a 600 s task timeout; stderr shows `gateway closed (1006)` followed by the embedded fallback). The ~18–19% totals are the 21 seed tasks divided by 100. On those seed tasks, OpenClaw executes normally: Baseline is 84.85–91.36.
- **OpenClaw GPT-5.4 and DeepSeek-V4-Pro, PostSkill.** On the seed tasks, 21/21 second-execution transcripts are fully empty, and the PostSkill *first pass* (a skill-free execution) already scores 3.44 and 0.00. The failure happens before any skill exists, which explains the 0 created PostSkill skills.
- **nanobot DeepSeek-V4-Pro, PreSkill and PostSkill.** 89/100 PreSkill executions return nanobot's "I've completed processing but have no response to give." fallback. In PostSkill the first pass also hits the fallback and finishes in ~14 s, so the whole PostSkill pipeline scores 0.00. Excluding the fallback tasks, Baseline is 84.3.
- **nanobot Qwen3.6-Plus, all modes (partial).** 34 / 25 / 32 tasks hit the same fallback and score 0. Excluding them, the scores are 84.9 / 79.0 / 78.6.

## Prediction method

1. **OpenClaw rows:** predicted score = 0.21 × observed seed-task score + 0.79 × predicted generated-task score. The generated-task prediction is the same model's nanobot generated-task score, cross-checked against two diagnostics:
   - `0084_venus-gpt-5-4_openclaw.json` (full suite, different route, not protocol-matched): generated tasks score 97.8 / 98.9 for PreSkill / PostSkill whenever they do not time out.
   - The 8-task OpenClaw diagnostic for GPT-5.4 mini in `review/reply_czyn.md`: 82.81 / 99.69 / 79.69 vs. nanobot 92.50 / 90.00 / 92.50.
2. **Failed PostSkill cells:** the seed-task score is predicted from the same row's Baseline, because a clean PostSkill first pass is a Baseline-equivalent run.
3. **Fallback-contaminated nanobot cells:** two scenarios, because the 20-task rerun (`evoclawbench/results/rebuttal_23ii_matched_subset_20260714/`) did not show the fallback string but still gave low DeepSeek skill-mode scores.

## Predicted conclusions under clean reruns

- **The runtime gap mostly disappears.** Strong models would sit within about 5 pp across OpenClaw and nanobot. On the seed tasks, OpenClaw Baseline is already higher than nanobot (84.85–91.36 vs. 80.96–84.85).
- **Skill effects stay small and mixed.** For most rows |Δ| would be ≤ 4 pp. That is within the Baseline-vs-first-pass replicate spread already visible in the data (−3.28 to +3.10 pp) and the 5–6 pp standard deviation of the 3-run subset.
- **Cost ordering does not change.** OpenClaw seed-task reuse-only (summary + second execution) efficiency is 0.38–0.39, i.e. 2.6× Baseline tokens. The second execution alone is 0.64–0.93, still more than Baseline.
- **DeepSeek-V4-Pro would be the only candidate for a real skill-mode collapse** (scenario B).
